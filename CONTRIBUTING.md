# Contributing

Instructors and teaching assistants maintain this public course website through
pull requests.

## Suggested workflow

1. Create a short-lived branch from the latest `main` branch.
2. Make the smallest student-facing change needed.
3. Preview the `site/` directory locally.
4. Open a pull request and complete the publication checklist.
5. Ask an instructor to review changes before merging.

Canvas is the official course platform. Public information on this website
should stay consistent with Canvas, but private Canvas content must not be
copied into this repository.

Never commit student information, grades, submissions, unpublished assessment
materials, internal teaching documents, credentials, or other confidential
data. If you are unsure whether something is public, ask an instructor before
adding it.
